# Supragya Jadhav — Profile Site

A digital resume site built on the same template as the root profile project.
Content is placeholders (`[...]` and `TODO` comments in `index.html`) until it's filled in from
[LinkedIn](https://www.linkedin.com/in/supragya-jadhav-0b9279166/) or a CV.

Open `index.html` in a browser to preview. The theme is set the same way as the main site, via the CSS variables in `styles/main.css`.
