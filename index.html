Selected work

Problems I've solved

Partition Maintenance Framework

Challenge
Partition administration across daily, monthly, quarterly and yearly data was largely manual.
What I did
Built metadata-driven automation that creates future partitions, removes expired data, validates functions, schemes and index alignment, and resumes after failures.
Result
A standardised, automated process that skips secondary replicas and flags bad configuration without stopping the run.

TLS Certificate Automation

Challenge
Certificate renewals across clustered SQL Servers were error-prone and hard to verify.
What I did
Wrote PowerShell rotation with pre-checks, thumbprint and encryption validation, listener tests, rollback and evidence capture.
Result
Safer renewals, with expiry alerting and proof that client connections are actually encrypted.

Backups for ~16 TB Databases

Challenge
Backing up and moving very large databases took too long.
What I did
Tuned striping, BufferCount and MaxTransferSize, and tested Azure storage and AzCopy transfers to separate SQL Server, storage and network limits.
Result
Practical, repeatable settings for backing up and transferring multi-terabyte databases.

Replica Health Monitoring

Challenge
Asynchronous replicas could look healthy while silently falling behind, causing log growth.
What I did
Designed a multi-signal check using queue sizes, send and redo rates, suspend state and lag, not just the standard sync status.
Result
Stalled replicas are caught early, before they turn into production incidents.
